# 19 - UI/UX Design - V8.3+

## Consistent Visual Identity
- Patient App: simple friendly, large readable, accessibility-friendly, low complexity, clear explanations, understandable language Data quality Good not raw technical unless advanced, multilingual-ready
- Doctor PC App: professional dense, technical, complete, physiological data raw/filtered PPG HR HRV GSR motion temp quality artifacts visualization time-series, advanced analysis circadian autonomic metabolic fingerprint multimodal AI, ultrasound all V8.3 capabilities, longitudinal comparison, notes, reports professional with disclaimer
- Doctor Android App: mobile review, patient list/search/profiles/recent measurements/trends/screening results/ultrasound/reports/notes/follow-up, not duplicate full PC
- Website: scientific accessible, serious modern scientific avoid excessive animations/fake claims/stock AI doctor/exaggerated promises/100% accurate/fake hospital branding, clean typography/scientific diagrams/clear sections/accessible colors/responsive/mobile/strong identity

- Header sticky top 0 z-index 100, logo left, nav links right flex wrap
- Nav links: color #cbd5e1, hover white, font 0.9rem
- Tabs: Patient App TabbedPanel Dashboard/Profile/Measurements/Symptoms/Cycle/Results/Find Care, Doctor PC QTabWidget Dashboard/Patients/Physiological/Advanced/Ultrasound/Longitudinal/Reports, Doctor Android similar
- Footer: Class 11 Research, GitHub, disclaimer

## Terminology Consistency
- Sense•Model•Predict•Personalize•Connect tagline
- Research / risk-screening output — not a medical diagnosis disclaimer everywhere
- Established measurement vs derived feature vs experimental research vs ML prediction vs clinical interpretation
- Data quality Good/Moderate/Poor understandable language
- USER-ENTERED vs MEASURED vs MODEL-INFERRED vs CLINICALLY-ENTERED vs IMAGE-DERIVED vs REAL vs SYNTHETIC vs DEMO/SIMULATED labels
- Provider verification verified/pending/unverified/demo never falsely label
- No prescription-drug sales no auto medication no treatment decisions

## Accessibility
Large readable fonts 16sp 18sp 20sp, clear buttons 50dp height spacing 10dp padding, simple navigation, multilingual-ready, offline-first, responsive grid two-col three-col auto-fit minmax 300px, mobile media query max-width 768px.

## No Excessive Animations
Minimal JS smooth scrolling only, no fake medical claims, no exaggerated promises, no 100% accurate, no fake hospital branding.
