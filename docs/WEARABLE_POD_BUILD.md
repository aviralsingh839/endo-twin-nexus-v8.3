# ENDO-TWIN NEXUS — Wearable Build

Use the single current build manual:

`docs/WEARABLE_AND_MEGA_BUILD_MANUAL.md`

The active V9 wearable is ESP32-S3 with an analog pulse sensor on GPIO4, GSR on GPIO34, and optional MPU6050/BME280/BH1750 sensors on I2C GPIO21/22. USB serial is 115200 and Wi-Fi/TCP uses port 7777 with CP3 frames.
