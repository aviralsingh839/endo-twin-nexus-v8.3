# ENDO-TWIN NEXUS Responsive Guide

## Target widths

320, 375, 390, 430, 768, 1024, 1280, 1440 and 1920px.

## Desktop

Use a persistent navigation rail/sidebar, compact top context bar and multi-column workspace. Charts may expand horizontally; dense tables should provide horizontal scrolling or column prioritization rather than clipping.

## Tablet

Collapse secondary navigation and reduce multi-column panels. Preserve touch targets and readable table rows.

## Mobile

Do not shrink the desktop dashboard. Use top app bar, bottom navigation for primary tasks, contextual screens, lazy lists and bottom sheets. Prioritize one primary action per viewport.

## Required states

Loading, empty, offline, error, partial-data, DEMO, LIVE and success must have explicit presentation and a next action where applicable.

## Accessibility

Maintain visible focus, sufficient contrast, semantic labels, touch-safe targets and reduced-motion behavior.
