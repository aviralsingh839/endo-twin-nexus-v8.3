CHRONO-PCOS V8.3+ - Garuda Linux Click-to-Launch
=================================================

Open this folder in Dolphin file manager.

Double-click:
  COMPLETE_LAUNCHER.sh → Complete Control Center GUI

Or directly double-click individual apps:
  PATIENT_APP.sh → Patient Application
  DOCTOR_PC.sh → Doctor PC Full Workstation
  WEBSITE.sh → Website
  FULL_SHOWCASE.sh → 16 Steps Science-Fair Demo
  DIAGNOSTICS.sh → System Check
  DATABASE.sh → Database 18 Tables
  CARE_FINDER.sh → Find Doctor/Clinic/Lab/Supplies
  etc.

First time:
  Double-click setup_garuda.sh → Run

If double-click opens text editor:
  Right-click .sh → Properties → Permissions → Is executable checked
  Dolphin → Settings → Configure Dolphin → General → Executable files → Run

All launchers:
  - Have executable permission
  - Valid shebang #!/usr/bin/env bash
  - Auto-detect project root
  - Use .venv/bin/python directly
  - Work from any working directory
  - Log to logs/
