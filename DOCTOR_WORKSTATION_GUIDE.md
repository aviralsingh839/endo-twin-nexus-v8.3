# Doctor Workstation Guide

Target workflow:
PATIENTS → ADD PATIENT → PATIENT PROFILE → CREATE TEST SESSION → CONNECT WEARABLE → LIVE MEASUREMENTS → SIGNAL QUALITY → PHYSIOLOGY → BASELINE → LONGITUDINAL → ULTRASOUND → MODELS → EXPLANATIONS → REPORT → AUDIT.

The current Android/desktop implementations include patient-scoped research/demo views. Persistent Add Patient/Create Session integration with the core database is the next implementation milestone; documentation must not pretend those demo controls are already live persistence.
