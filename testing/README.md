# Hardware testing

Use this sequence for each sensor:

POWER TEST → CONNECTION TEST → RAW SIGNAL TEST → QUALITY TEST → CALIBRATION → KNOWN-GOOD REFERENCE → STRESS TEST → LONG-DURATION TEST → DATA STORAGE TEST

Failure scenarios: disconnected sensor, loose wire, zero/flatline signal, excessive noise, motion artifact, corrupt packet, missing packets, wrong sampling rate, serial disconnect/reconnect, unavailable sensor and invalid values.
